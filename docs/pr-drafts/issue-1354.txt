server: share ordered addresses.dat sources for server-list updates

Part of #1354. Local prerequisite for revising #1923; do not publish yet.

Read addresses.dat when an update begins instead of caching it at application startup. Preserve the file, accept HTTP and HTTPS, ignore comments and blank lines, skip invalid URLs, and retain the first occurrence of each URL. Use an independent snapshot for the startup auto-update sequence and a size_t cursor so lists are not truncated to 255 entries. The shared reader is available for manual download fallback in the next change.

No new default source is installed. The proposed emuling.gitlab.io source came from #1354; its operator and list-generation policy have not been established here. A shipped backup requires project agreement.

Configuration: local users may use the existing Servers preferences editor; daemon administrators edit addresses.dat in the daemon configuration directory. Remote clients do not gain a new setting or edit the daemon file through this change. Existing primary URL and startup update enablement remain unchanged.

Validation: see the local validation record after checks finish.
