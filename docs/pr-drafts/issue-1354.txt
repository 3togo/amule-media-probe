server: retry failed server-list downloads using addresses.dat

Local revision of https://github.com/amule-org/amule/pull/1923, part of #1354. Do not publish yet.

Depends on pr/1354-server-sources-draft. Its shared addresses.dat reader and startup regression test are merged into this branch. Published #1923 history is preserved, with upstream master merged before the prerequisite.

Attempt the requested URL first, then each distinct HTTP/HTTPS URL in addresses.dat in file order until one downloads and parses completely. Apply this to first-run requests, the local GUI, and EC requests used by remote clients, including explicitly entered alternate URLs. Skip the originally requested URL if it also occurs in addresses.dat. Stop after success, a not-modified result, cancellation or exhaustion.

Capture the source list when the sequence begins. Ignore overlapping manual download requests without changing that snapshot; keep automatic update sources and download state separate. Preserve complete parsing before imports and existing entries after invalid/truncated downloads. Retain local startup-file salvage.

Remove Ed2kServersFallbackUrl and its proposed default source. Empty or absent addresses.dat disables additional attempts. No new default backup is shipped; source selection requires project agreement. Existing configurations from the earlier PR should place their intended fallback in addresses.dat instead of the removed setting.

Validation: see server-fallback-validation.txt. The fallback integration test now covers 17 local-HTTP/daemon scenarios, including ordered retries, malformed lists, existing entries, first run, explicitly entered URLs, duplicates, live file edits, overlapping requests and HTTP 304. Native GUI Cancel remains a manual runtime check; its cancellation result handling is retained.
